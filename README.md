Data Analytics Internship – Task 16 (Simple Profit Analysis)

This repository contains my submission for Task 16 of the Data Analytics Internship.

Dataset - Sample Superstore Dataset

Objective - The objective was to compare total profit across product categories and understand basic profitability using Excel.

Tools Used
1. Microsoft Excel
2. Sample Superstore Dataset
3. GitHub

Analysis Performed
1. Grouped profit data by Category
2. Calculated total profit for each category using SUMIF
3. Calculated average profit for each category using AVERAGEIF
4. Compared total and average profit across categories
5. Created a column chart for Total Profit by Category

Final Results
1. Furniture: Total Profit $18,421.81; Average Profit $8.70
2. Office Supplies: Total Profit $122,364.66; Average Profit $20.35
3. Technology: Total Profit $145,454.95; Average Profit $78.75
4. Highest Total Profit Category: Technology
5. Highest Total Profit: $145,454.95

Files
1. Task 16.xlsx - Excel workbook containing Raw Data and Profit Analysis
2. README.md - Summary of profit analysis

Conclusion - The Sample Superstore dataset was successfully analyzed using Excel to compare profitability across categories. Technology had the highest total and average profit, and a chart was created to present the comparison.
